# V1.0 RO — How to Fish — Roulette Operator

Meet **RO**, a small and delightfully silly single-player roulette cheat created specifically for *How to Fish*.

RO started as a personal reverse-engineering study built purely for fun. Along the way, it became an experiment in Unity assembly inspection, runtime module injection, physics control, build compatibility, and safe restoration. Its job is wonderfully simple: choose **Black**, **Red**, or **Green**, spin the roulette, and watch RO guide the ball toward your selected color.

This project is shared for personal experimentation, learning, and harmless fun. It was never created to damage the game, interfere with other players, or undermine its developers. Study it, test it, modify it, or use it for the world's least serious betting session.

**Simple. Silly. Let's bet!**

## Highlights

- Choose Free, Black, Red, or Green before each spin.
- Compatible-build detection based on roulette structure—not one fixed game hash.
- Support for standard and renamed Unity installations.
- Build-specific local patch generation.
- Automatic SHA-256-addressed backups.
- One-click restoration of the matching original assembly.
- Safe refusal when a build is not compatible.
- Fully English, vibrant Windows interface with a custom pixel-art icon.

## Installation

1. Download `RO-v1.0-Windows-x64.zip` below.
2. Extract the complete ZIP to a folder.
3. Close *How to Fish*.
4. Run `How to Fish - Roulette Operator.exe`.
5. Select the game executable if RO does not find it automatically.
6. Click **INSTALL / REPAIR**, open the game, and select a color before spinning.

Use **FREE** for the game's unassisted roulette behavior. Close the game and use **RESTORE ORIGINAL** whenever you want to remove RO's local patch.

## Compatibility note

RO supports tested builds and other builds that preserve the required roulette structure. If a future update changes that structure, RO will refuse to patch it safely instead of risking damage to the installation.
